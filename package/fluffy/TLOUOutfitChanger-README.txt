TLOU Outfit Changer v1.0.0 - The Last of Us Part I (PC)

Every Joel and Ellie outfit and weapon skin, without finishing the story.
Extras > Skins and the in-game Skins menu are open on any save, and every
skin is owned without spending points, including the six weapon skins
that the Deluxe Edition gives early. Points, Gameplay Modifiers and trophies are
not changed. Settings: TLOUOutfitChanger.ini

INSTALL WITH FLUFFY MOD MANAGER
  Put this zip in  Fluffy Mod Manager\Games\TLOU\Mods\  and tick
  "TLOU Outfit Changer" in Fluffy. Untick it to uninstall.
  Install while the game is closed.

INSTALL MANUALLY
  Copy xinput1_4.dll and TLOUOutfitChanger.ini into the game folder
  (the folder with tlou-i.exe), e.g.
  C:\Program Files (x86)\Steam\steamapps\common\The Last of Us Part I\
  modinfo.ini and screenshot.png are only for Fluffy.

UNINSTALL MANUALLY
  Delete xinput1_4.dll, TLOUOutfitChanger.ini and TLOUOutfitChanger.log
  from the game folder.

WORKS WITH TLOU INFINITE AMMO
  Infinite Ammo loads as version.dll, this mod as xinput1_4.dll, so both
  can be installed at the same time, with Fluffy or by hand.

CHECK IT WORKS
  After starting the game, TLOUOutfitChanger.log in the game folder should
  end with "installed: Skins menus open, every skin owned".

Supported: Steam, game version 1.1.4.0. If the game updates and the mod's
code patterns are no longer found, the mod writes the reason to the log and
does nothing.
